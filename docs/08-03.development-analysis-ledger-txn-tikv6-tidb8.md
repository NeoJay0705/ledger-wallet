Runs were single observations; no repeatability is implied.

Placement disclosures: in k6t8 logical CPUs N and N+8 share a physical core. From the listed cpusets, TiKV/client pairs are 0/8 and 1/9; TiDB-server/TiKV pairs are 4/12, 5/13, and 6/14; TiDB-server pairs are 3/11 and 7/15. Client, PD, and sampler share logical CPUs 8-9. The placements alone do not establish actual contention. TiKV has a quota of 3 per store. Each batch/configuration is a single primary run (extra runs, if any, are supplemental).

## 6. Limitations and file index

- The three scheduled batches have one primary run per new configuration. A single run does not estimate run-to-run variance; any extra run is reported separately and never silently substituted, except the established successful flush-rerun replacement rule.
- CPU placement and quota are controlled descriptions, not proof of CPU contention or an explanation for throughput differences. The comparison references are earlier measurements.
- File index: `artifacts/fixconn-tidb-k4t4-n16.csv`, `artifacts/fixconn-tidb-k6t8-n16.csv`; references `artifacts/fixconn-tidb-c4-n16.csv` and `artifacts/fixconn-tidb-c8x-n16.csv`.
